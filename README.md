# Pear Music — Quiénes somos

Sitio web ficticio hecho para el curso **Storytelling en Comunicación Organizacional** (UCU), por Domínguez y Machado, 2026.

Pear Music es el nombre con el que rebautizamos a Apple Music para este ejercicio. Los datos e hitos son los de ese servicio, tomados de fuentes públicas. No es un sitio oficial.

## Qué tiene

- **Perfil**: propósito, misión, datos clave, a quién le hablamos, valores.
- **Historia**: línea de tiempo 2014–2025.
- **Artistas**: frases reales de artistas sobre Apple Music, con su fuente.
- **Podcast "Entre canciones"**: episodio 1 para escuchar y próximos episodios bloqueados.
- **Nuestro sonido**: logo sonoro, cortina, efecto de favoritos y comparador comprimido vs. Lossless.

## Cómo verla

Es un sitio estático (HTML, imágenes y MP3), sin instalar nada.
Para publicarla: *Settings → Pages → Deploy from a branch → main / root*.
